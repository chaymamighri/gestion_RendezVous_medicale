# Gestion des Rendez-vous Médicaux

## Description

Cette application web interne vise à faciliter la gestion quotidienne d’un cabinet médical en remplaçant les procédures administratives sur papier par une solution numérique.

Elle permet au **secrétaire** de gérer les patients, d’organiser les rendez-vous et de consulter les informations administratives. Le **médecin** peut consulter son planning, visualiser les rendez-vous programmés et accéder aux informations des patients pour faciliter le suivi des consultations.

L’application dispose d’une interface adaptée aux responsabilités de chaque utilisateur, avec une authentification sécurisée et une gestion des accès par rôle.

## Fonctionnalités principales

* Gestion des patients et de leurs informations.
* Planification et gestion des rendez-vous médicaux.
* Consultation du planning et des rendez-vous programmés.
* Accès aux informations des patients selon le rôle.
* Authentification et gestion des rôles : secrétaire et médecin.
* Communication entre le frontend et le backend via une API REST.

## Technologies utilisées

* **Frontend :** React.js, HTML, CSS, JavaScript
* **Backend :** Node.js, Express.js
* **Base de données :** MongoDB
* **Authentification :** JWT
* **API :** REST API
* **Tests des API :** Postman
